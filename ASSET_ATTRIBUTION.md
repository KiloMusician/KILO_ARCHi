# Source and runtime artwork

ARCHi and QiMon are developed by Patrick “pH” Hampton. The included project-authored source, documentation, vector icons and runtime companion PNGs are distributed under the repository's MIT license. Third-party packages retain their own licenses.

The Original companion is drawn by the native SwiftUI renderer. The included Pearl and Lumen PNGs were authored locally in Blender from ARCHi's existing design; the authoring records report no external assets. This source release includes the rendered runtime assets needed to build the app. Editable Blender projects and machine-specific authoring records are not included in this first release.

The Broken Relay rules were adapted from Hampton's existing SigGraph Hackathon work. See [the integration provenance note](docs/siggraph-local-companion-integration.md).

MIT reuse permission is separate from a claim that Hampton authored or authenticated a derivative. The proposed Hampton Designed seal describes creator provenance and balanced game specialties; copying a seal or creating a UID does not establish that provenance. See [Hampton Designed](docs/HAMPTON_DESIGNED.md). This policy does not add restrictions to the MIT code license.

No model weights, Unity or Blender installations, paid Reactor SDK runtime, credentials or user records are bundled in the repository. External tools, services and models have their own terms and prerequisites.
